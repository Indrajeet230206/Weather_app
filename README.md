# Weather App

A weather application built using React, JavaScript, Material UI, and the OpenWeatherMap API.

## Features

- Search weather by city name
- Display current temperature in Celsius
- Show minimum and maximum temperatures
- Display humidity and feels-like temperature
- Show weather conditions and icons

## Technologies Used

- React
- JavaScript
- Material UI
- CSS
- OpenWeatherMap API
- Vite

## Installation

1. Clone the repository.
2. Navigate to the project folder.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

## API Configuration

Get an API key from [OpenWeatherMap](https://openweathermap.org/api) and configure it in the application.
